**Source Data**

The analysis uses a publicly available India Hospital Readmission Dataset (2015–2024) from Kaggle. The dataset was downloaded on July 31, 2026 and contains multiple related source tables used for the analysis.

Source: https://www.kaggle.com/datasets/digutlaranjithkumar/india-hospital-readmission-dataset-20152024?utm_source=chatgpt.com&select=diagnoses.csv

The source data were subsequently profiled, assessed for quality, transformed through ETL, and structured into analytical tables for exploratory analysis, predictive modeling, and Tableau reporting.
